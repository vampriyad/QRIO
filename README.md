# 📱 Qrio

Welcome! 👋

Qrio is a simple, fast, and elegant QR code generator built for anyone who needs to create professional QR codes in seconds. Whether it's for a website, Wi-Fi network, contact card, or social media profile, Qrio makes the process quick and effortless.

Customize your QR code, preview changes instantly, and download it in high quality—all directly in your browser.

## 🚀 Live Website

Try Qrio here:

https://vampriyad.github.io/QRIO/

## ✨ Features

- Generate QR codes instantly
- Support for URLs, text, email, phone, Wi-Fi, vCards, and more
- Live preview
- Custom colors and styles
- Logo upload
- Download as PNG, SVG, or PDF
- Light and dark mode
- Fully responsive design
- No account required
- Works entirely in your browser
